# 不可忽视条件（硬性约束）

> 本文档记录项目开发、测试、部署过程中**不可绕过、不可忽视**的硬性约束。任何新需求、新代码、新脚本在落地前必须先对照本文档检查。违反约束的改动一律不允许合入。

## 约束一：项目中禁用 Docker

**生效日期**：2026-09-14（主人指令）

### 约束内容

本项目**全面禁用 Docker 及一切依赖 Docker 的技术**，包括但不限于：

| 禁用项 | 说明 |
|---|---|
| Docker / Docker Compose | 不得用于基础设施部署（MySQL / Redis / Nacos / ES / MailHog 等一律原生安装） |
| Testcontainers | 不得用于任何测试（相关测试已 `@Disabled`，见下） |
| Dockerfile / 镜像构建 | 不得新增；部署采用裸机 + 启动脚本方式 |
| CI/CD 中的 Docker 执行器 | 未来搭建流水线时不得选择 Docker-based runner |

### 已落地的禁用措施

1. **测试**：4 个 Testcontainers 流程测试已加 `@Disabled`（保留用例代码供日后改造）：
   - `moyue-content` → `com.moyue.read.BookshelfFlowTest`
   - `moyue-social` → `com.moyue.im.ImMessageFlowTest`、`com.moyue.blog.BlogLikeFlowTest`
   - `moyue-commerce` → `com.moyue.points.PointsOrderFlowTest`
   - 待办：这些用例后续改造为 **H2**（参考 `moyue-system` 既有 H2 测试先例）或直连原生 MySQL 的集成测试后再启用。
2. **脚本**：`scripts/start-all.sh`、`scripts/smoke-test.sh` 中的 `docker compose up -d` 提示已改为原生部署提示。
3. **依赖**：Testcoordinates 相关依赖暂保留在 3 个模块 pom 的 test scope（仅为让已禁用用例可编译）；改造完成后应移除依赖与根 POM 的 `testcontainers.version` 属性。

### 原生部署替代方案

| 组件 | 替代方式 |
|---|---|
| MySQL 8.x | Windows 服务 / 官方安装包原生安装 |
| Redis 7.x | 原生安装（或 Windows 可用的 Memurai 等兼容实现） |
| Nacos 2.x | 官方发行包 + `startup.cmd` 裸机运行 |
| Elasticsearch 8.13.4 | 官方 ZIP 原生安装 + IK 插件（见 `deliverables/ops/ELK安装配置手册.md`） |
| MailHog | 原生可执行文件，或直接跳过（邮件走真实/测试 SMTP） |

### 给开发者的提醒

- 写新测试**禁止**引入 `@Testcontainers` / `@Container` / `@ServiceConnection`；数据库集成测试一律走 H2（`moyue-system` 有成熟先例）或原生 MySQL。
- 写部署文档/脚本**禁止**出现 `docker`、`docker-compose`、`containerd` 等指令；基础设施安装一律给原生步骤。
- 若未来确需容器化，必须由主人显式撤销本约束并更新本文档，任何人不得自行解除。
