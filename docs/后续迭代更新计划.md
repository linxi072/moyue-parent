## 1. 候选特性池（P2 及之后）

每条含：价值、涉及模块（基于真实代码）、关键技术点、验收标准、规模（S<3d / M 3–8d / L>8d）、约束合规。

### P2-A 分类服务独立化
- **价值**：去除 `BookService.CATEGORY_NAMES` 硬编码 3 类（玄幻/都市/悬疑），运营后台可自助配置分类（增删改、排序、图标），支撑更多品类与精确检索/推荐。
- **涉及**：`com.moyue.content`（新增 `category` 包 + `category` 表 + `CategoryService/Mapper/Controller`）、`com.moyue.system`（运营后台分类管理，复用 RBAC）、`com.moyue.search`（分类字段召回）、`com.moyue.content`（新增 `CategoryClient`）。
- **技术点**：Flyway V19 加 `category` 表（幂等，information_schema 判断）；`BookEntity` 关联 `category_id` 替换硬编码；管理端 CRUD（`@RequiresPermissions`）；分类变更触发 `book` ES 索引重建 hook；检索/推荐按 `category_id` 过滤；分类逻辑删除加 `@TableLogic`。
- **验收**：分类可后台增删改；书城按分类筛选；ES 索引含分类；单测覆盖 CRUD + 逻辑删除。
- **规模**：M ｜ **约束**：`@TableLogic`、`V19` 幂等、H2 测试。

### P2-B 订阅 / 会员体系
- **价值**：AI 话术已提「书币会员灰度」但无实现；建会员等级 / 订阅包月 / 权益（免广告、折扣、专属徽章），商业化延伸。
- **涉及**：`com.moyue.commerce`（新增 `member` 包：等级/订阅订单/权益校验）、`com.moyue.account`（会员标识）、`com.moyue.system`（会员配置）、`com.moyue.commerce`。
- **技术点**：会员等级 + 有效期；包月/连续订阅（**支付为外部依赖，先 Stub 状态机 + 配置驱动降级**，同 P1 风格**）；权益注解/拦截器（免广告等）；与积分/打赏分成解耦。
- **验收**：开通会员→权益生效；到期自动降级；订阅记录可查。
- **规模**：L（建议分期：先会员标识+权益框架，再接支付）｜ **约束**：支付外部依赖走配置降级，不阻断。

### P2-C 风控反作弊·行为层
- **价值**：当前仅有内容安全（敏感词 AC 机审），缺行为风控：刷量/刷分/盗号/薅积分；补规则引擎。
- **涉及**：`com.moyue.risk`（新增 `behavior` 包：行为采集 + 规则引擎 + 风控决策）、`com.moyue.points`（积分发放 Hook 校验）、`com.moyue.auth`（登录/设备指纹）。
- **技术点**：行为事件（登录/签到/兑换/打赏）异步采集；规则（频控/同设备多账号/积分异常）**配置化非硬编码**；命中→限流/标记/人工复核；复用内容安全通知链路（`MessageDispatchClient`）。
- **验收**：模拟刷分被拦截；规则可配置热刷；看板含行为风控指标。
- **规模**：L ｜ **约束**：规则配置化；降级不阻断主链路。

### P2-D 书架实时同步
- **价值**：当前书架同步靠共享表 + 缓存拉取，存在 ≤5min 陈旧窗口（`docs/时序图/书架同步.md`）；升级为 WebSocket 近实时，体验对齐 IM。
- **涉及**：`com.moyue.social`（复用 `ImWebSocketHandler` 建书架广播通道）、`com.moyue.content`（`ReadService` 变更后发领域事件）。
- **技术点**：阅读行为→领域事件→WebSocket 推同用户在线端；幂等；离线合并。
- **验收**：多端开书架，一端变更另一端秒级刷新（**无前端则先落后端推送能力 + 单测**，前端待 P2-F）。
- **规模**：M ｜ **约束**：H2 单测覆盖事件发布/消费。

### P2-E 社区互动深化：关注流 / 动态
- **价值**：作者/读者关注、动态信息流，强化 UGC 生态与留存。
- **涉及**：`com.moyue.social`（新增 `follow/feed` 包）、`com.moyue.content`（作品动态）、`com.moyue.search`（feed 召回）。
- **技术点**：关注关系表；作品发布/打赏/完结→动态；信息流聚合（时间线 + 兴趣）；分页游标。
- **验收**：关注作者→信息流出现其动态；取关生效。
- **规模**：L。

### P2-F 多端 / 小程序 + 前端契约消费端
- **价值**：补齐「无前端项目」缺口（`项目现状` §6-#12），让 `moyue-contract` 生成的 TS 客户端被真实使用；小程序触达。
- **涉及**：新增 `moyue-frontend`（Vue/React）、`单体入口（原 moyue-gateway）`（小程序路由）、`com.moyue`（已有 TS 客户端 sample）。
- **技术点**：前端脚手架；消费契约 TS；小程序 BFF；网关新增小程序入口。
- **验收**：基础书城/阅读/客服前端可用；契约被消费。
- **规模**：XL（跨端，建议**独立立项**，不并入后端迭代）。

### P2-G 可观测性增强
- **价值**：Sentinel 已接，补分布式追踪 / 指标 / 日志聚合，支撑运维（呼应《运维部署手册》）。
- **涉及**：全服务；`com.moyue.common`（接入 Micrometer/OpenTelemetry）、网关。
- **技术点**：TraceId 透传（在 `X-User-Id` 基础上扩展）；指标暴露 Prometheus；日志聚合（ELK 已有安装手册）；看板。
- **验收**：关键链路 TraceId 串联；Prometheus 指标可采；ES 日志可查。
- **规模**：M。

### P2-H 跨服务共享表解耦（架构债）
- **价值**：`commerce.com.moyue.author` 与 `system.com.moyue.operation` 双映射同一 `author_income` 表（非 进程内调用），耦合高风险；收敛为事件/进程内调用。
- **涉及**：`com.moyue.commerce`、`com.moyue.system`、`com.moyue`。
- **技术点**：稿酬变更发领域事件→system 监听落统计；或 进程内调用 调用；去双写。
- **验收**：单服务写 `author_income`；跨服务经事件/进程内调用；无双写。
- **规模**：M（**须谨慎，涉及 P0 已落地稿酬链路，不得回退打款闭环**）。

### P2-I 网关直连防护（安全）
- **价值**：网关「信任头」模型下，服务端口直连可伪造身份（`项目现状` §6-#11）；补内网隔离 / mTLS / 二次校验。
- **涉及**：`单体入口（原 moyue-gateway）`、`com.moyue.common-security`。
- **技术点**：仅允许网关网段；或内部调用携带服务令牌/签名；`HeaderInterceptor` 增加来源校验（**原生证书，禁用 Docker 不受影响**）。
- **验收**：绕过网关直连被拒；内部调用可验。
- **规模**：M。

### P2-J 文档与代码对齐修正
- **价值**：README 路线图 / Flyway / 索引描述漂移（`项目现状` §6-#10/#12）；修正避免误导。
- **规模**：S ｜ 纯文档。

### P2-K 测试覆盖补齐
- **价值**：`auth/account/commerce/social/message` 关键路径单测仍缺（`项目现状` §6-#8）。
- **规模**：M（持续）｜ **约束**：H2，禁 Docker。

**不纳入后端迭代（独立大项）**：P2-F 多端/小程序（XL，跨端，建议单独立项）。
